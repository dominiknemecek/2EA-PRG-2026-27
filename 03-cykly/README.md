# 03 — Cykly

Opakování kódu: `for`, `while` a `do-while`.

## Co byste měli umět po této kapitole

- Používat `for`, když dopředu víme, kolikrát se má cyklus opakovat.
- Používat `while` a `do-while`, když počet opakování dopředu neznáme.
- Vysvětlit rozdíl mezi `while` a `do-while` (kdy se tělo cyklu provede
  aspoň jednou).
