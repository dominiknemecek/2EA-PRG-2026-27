# 05 — Funkce a struktury

Jak si rozdělit program na menší, znovupoužitelné kusy (funkce) a jak si
vytvořit vlastní datový typ, který drží dohromady víc hodnot (`struct`).

## Co byste měli umět po této kapitole

- Napsat vlastní funkci s parametry a návratovou hodnotou a zavolat ji.
- Vysvětlit rozdíl mezi předáním parametru hodnotou a ukazatelem (odkazem).
- Definovat vlastní `struct` a pracovat s jejími poli přes `.`.
