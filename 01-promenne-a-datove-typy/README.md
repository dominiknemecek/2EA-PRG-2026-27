# 01 — Proměnné a datové typy

Základní stavební kámen každého programu: jak deklarovat proměnnou, jaké
základní datové typy C nabízí a jak se čte vstup od uživatele.

## Co byste měli umět po této kapitole

- Deklarovat proměnnou se správným typem (`int`, `float`, `double`, `char`).
- Použít `printf` pro výpis a `scanf` pro načtení hodnoty od uživatele.
- Vysvětlit rozdíl mezi celočíselnými a desetinnými typy a proč na tom
  záleží (např. dělení dvou `int` useknutím desetinné části).
