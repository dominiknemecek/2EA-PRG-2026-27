# 02 — Podmínky

Jak se program větví podle vstupu: `if` / `else if` / `else` a `switch`.

## Co byste měli umět po této kapitole

- Používat `if` / `else if` / `else` a logické operátory (`&&`, `||`, `!`).
- Používat `switch` a vědět, kdy je čitelnější než dlouhý řetězec `if`.
- Vysvětlit, proč `switch` v C potřebuje `break` u každé větve.
